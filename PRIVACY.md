# Règles de confidentialité — automatic-youtube-downloader

*Privacy policy — automatic-youtube-downloader*

automatic-youtube-downloader est un outil personnel, auto-hébergé. Chaque personne qui l'utilise l'installe dans son
propre projet Google Cloud, avec sa propre autorisation Google.

**Données consultées.** L'application utilise uniquement la permission Google Drive `drive.file`. Elle n'a accès
qu'aux fichiers et dossiers qu'elle a créés elle-même. Elle ne peut ni lire, ni modifier, ni supprimer les autres
fichiers du Drive.

**Usage.** L'application dépose dans le Drive de l'utilisateur des fichiers audio issus de playlists YouTube
publiques que l'utilisateur a lui-même choisies.

**Partage.** Aucune donnée n'est envoyée à un tiers, vendue ou utilisée à des fins publicitaires. Le token
d'autorisation est stocké uniquement dans le projet Google Cloud de l'utilisateur (Secret Manager).

**Révocation.** L'accès peut être retiré à tout moment sur https://myaccount.google.com/permissions

*English summary: this self-hosted tool only uses the `drive.file` scope, only accesses files it created, and never
shares data with third parties. Access can be revoked at https://myaccount.google.com/permissions.*
